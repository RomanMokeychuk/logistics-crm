# FURA — AI-продажі: запуск

Агенти знаходять контакти клієнтів з митної бази, готують перші листи й розбирають відповіді.
**Жоден лист не йде клієнту без кнопки «Надіслати»** на сторінці «AI-продажі».

```
Excel з митної бази ─▶ Пул клієнтів ─▶ Пошук контактів ─▶ Чернетка листа ─▶ Sales: «Надіслати»
                                       (реєстр → сайт →        (Claude, за фактами   │
                                        Snov/Apollo/RR)         з митної бази)       ▼
                         Картка в «Ліди» ◀── Відповідь клієнта ◀── Лист + нагадування (4-й, 10-й день)
                         + Telegram Sales      (агент розбирає)
```

## Нові файли

| Файл | Що це |
|---|---|
| `sales_agent.sql` | Таблиці `sales_prospects`, `sales_contacts`, `sales_messages`, `sales_suppression` + доступ + розклад |
| `bot/fura-sales.ts` | Серверна функція: пошук контактів, листи, відправка, відповіді, відписка |
| `sales-agent.html / .js / .css` | Сторінка «AI-продажі» |
| `shell.js` | + пункт меню «AI-продажі» |
| `leads.js` | + джерело ліда «AI-агент (митна база)» |

## Крок 1. База (5 хв)

Supabase → SQL Editor → вставити `sales_agent.sql` → Run.
Має показати 4 таблиці. (`agent_bids.sql` уже виконаний — звідти функція `is_active_staff()`.)

## Крок 2. Пошта для листів (1 день — через DNS)

1. Купити **окремий домен** для розсилки, напр. `grandar-logistics.com` (не основний — щоб основний не потрапив у спам).
2. Зареєструватися в [Resend](https://resend.com) → Domains → додати домен → прописати DNS-записи SPF, DKIM і DMARC у реєстратора.
3. Створити ящик `sales@…` для відповідей (Google Workspace / Zoho) — туди клієнти відповідатимуть.
4. **Прогрів:** перші 2 тижні — 10–15 листів на день, далі до 40. Ліміт ставиться секретом `SALES_DAILY_LIMIT`.

## Крок 3. Секрети функції

Supabase → Edge Functions → Secrets:

| Секрет | Обов'язково | Приклад / примітка |
|---|---|---|
| `ANTHROPIC_API_KEY` | так | вже є для fura-agent |
| `RESEND_API_KEY` | так | з Resend → API Keys |
| `SALES_FROM` | так | `Грандар <sales@grandar-logistics.com>` |
| `SALES_REPLY_TO` | ні | `sales@grandar-logistics.com` |
| `SALES_CRON_SECRET` | так | будь-який довгий випадковий рядок |
| `SALES_DAILY_LIMIT` | ні | `15` на прогріві, потім `40` |
| `SALES_SIGNATURE` | ні | `Олександр, Грандар — автоперевезення\n+380…` |
| `OPENDATABOT_API_KEY` | ні | ключ API Opendatabot |
| `OPENDATABOT_URL` | ні | шаблон з `{code}` і `{key}`, якщо у вашому тарифі інша адреса |
| `YOUCONTROL_API_KEY`, `YOUCONTROL_URL` | ні | шаблон URL з `{code}` і `{key}` з документації YouControl API |
| `SNOV_CLIENT_ID`, `SNOV_CLIENT_SECRET` | ні | Snov.io → API |
| `APOLLO_API_KEY` | ні | Apollo → Settings → API |
| `ROCKETREACH_API_KEY` | ні | RocketReach → API |
| `PAID_MIN_SCORE` | ні | `7` — з якого score вмикати платні бази |
| `SALES_AUTO_FOLLOWUP` | ні | `true` — нагадування без схвалення (вмикати, коли тексти перевірені) |

Без ключа платного джерела агент просто пропускає його. На сторінці зверху видно, що підключено.

**Веб-пошук Claude:** агент шукає сайт і контакти через інструмент web search у Claude API.
Він має бути дозволений для вашої організації в Claude Console (налаштування організації; оплата — за кожен пошук). Якщо він вимкнений, у картці буде «немає відповіді Claude» — агент тоді шукає тільки через реєстр і платні бази.

## Крок 4. Розгортання

```bash
supabase functions deploy fura-sales --no-verify-jwt
```
`--no-verify-jwt` потрібен для посилання «Відписатися» і розкладу; співробітників функція перевіряє сама (як fura-agent).

## Крок 5. Розклад (кожні 10 хв)

Database → Extensions → увімкнути `pg_cron` і `pg_net`.
У `sales_agent.sql`, блок 7 — розкоментувати, підставити `SALES_CRON_SECRET`, виконати (службовий ключ не потрібен).
За один запуск агент: шукає контакти для 3 компаній (спершу найвищий score), готує до 5 чернеток, пише нагадування, термін яких настав.

## Крок 6. Відповіді клієнтів

Два варіанти:
- **Автоматично:** вхідна пошта домену → вебхук на
  `https://prbfscwmemshwigiftha.supabase.co/functions/v1/fura-sales?inbound=1&key=<SALES_CRON_SECRET>`
  (Resend Inbound, Cloudflare Email Routing + Worker, Zapier/Make — будь-що, що надішле JSON з полями `from`, `subject`, `text`).
- **Вручну:** у картці клієнта — «Додати відповідь клієнта» (вставити текст). Агент так само розбере й оновить «Ліди».

Що робить агент з відповіддю: `цікавиться / просить ставку` → лід на етап «Переговори» + Telegram відповідальному Sales;
`пізніше` → дата наступного контакту в картці ліда; `відмова / не пишіть` → «Відмова» + стоп-лист (більше ніколи не пише).
Будь-яка жива відповідь скасовує нагадування.

## Як працювати щодня

1. **Раз на місяць:** аналіз митної бази → Excel → «Пул клієнтів» → «Обрати Excel» → «Завантажити в пул».
2. Відфільтрувати (сегмент, score ≥ 7, експорт/імпорт) → «Обрати показані» → **«Шукати контакти»**.
3. **Щодня:** вкладка «На схвалення» — прочитати, поправити, «Надіслати». 10–15 хв на 20 листів.
4. «Без e-mail → дзвінок» — компанії, де знайшли тільки телефон: ці — менеджерам на дзвінки.
5. Відповіді приходять у Telegram і на вкладку «Відповіді»; картка вже в «Ліди».

## Правила, вшиті в агента

- Пише тільки з фактів митної бази. Не вигадує ставок, кейсів, клієнтів, термінів, гарантій.
- Платні бази — тільки для score ≥ `PAID_MIN_SCORE` і тільки якщо безкоштовні джерела не дали e-mail людини з потрібною посадою (логістика, ЗЕД, закупівлі).
- Кожен контакт зберігається з джерелом і посиланням — Sales бачить, звідки він.
- У кожному листі — посилання «Відписатися» і заголовок List-Unsubscribe. Відписаних агент не чіпає ніколи.
- Денний ліміт перших листів — щоб домен не потрапив у спам.
- LinkedIn агент не парсить (це заборонено правилами LinkedIn і веде до бану) — профілі з'являються тільки з Apollo / RocketReach.

## Що перевірити після першого запуску

Адреси API платних сервісів змінюються між версіями й тарифами. Після підключення ключа запустіть
«Знайти контакти зараз» на 2–3 компаніях і подивіться блок «Що шукав агент» у картці:
`HTTP 401/404` біля Snov / Apollo / RocketReach / Opendatabot означає, що треба звірити адресу з документацією вашого тарифу
(для Opendatabot / YouControl — секрет `*_URL`; для інших — функції `fromSnov`, `fromApollo`, `fromRocketReach` у `bot/fura-sales.ts`).

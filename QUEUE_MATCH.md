# FURA — підбір машин з «Черги» під запит

У картці запиту з завантаженням за кордоном з'являється кнопка **🚚 Машини з черги**.
Вона одразу показує перевізників, чиї машини **щойно виїхали** або **зараз виїжджають** з України
в бік країни завантаження, — з оцінкою, чи встигають до дати, і поясненням, чому вони в списку.
Обраних — кнопкою **«Запросити ставки»** в «AI-агенти» (там вони вже відмічені).

## Логіка

| Сигнал | Звідки | Бали |
|---|---|---|
| Встигає до дати завантаження | див. «Куди їде машина з вантажем» нижче | до 40 |
| Розвантажиться в країні завантаження / поруч | прогноз за експортною історією | +15 / +9 (<450 км) / +4 (<900 км) / −6 (>1600 км), × впевненість |
| Розвантажується в тому ж місті, де завантаження | міста з `carrier_routes.cities` | +6 |
| Виїзд у «правильну» країну (Польща для PL, Словаччина/Польща для DE…) | `echerha_queue` / `echerha_passed` | 10 / 4 |
| З вантажем → шукатиме зворотний | тип черги | +8 |
| Угоди з нами | `deals` | +5 за угоду, до 20 |
| Возить цей напрямок (митні дані) | `carrier_routes`, Імпорт × країна | до 15 |
| Telegram / телефон | `carriers` | +8 / +3 |
| Кілька машин перевізника у вікні | черга | до +9 |
| Негативні відгуки за 60 днів («Не відповів», «Немає такого причепу»…) | `carrier_feedback` | −10 за кожен |
| «Сховати з підбору» | `carriers.match_hidden_*` | не показується |

## Куди їде машина з вантажем

Місця розвантаження в Черзі немає, тому воно прогнозується за експортною історією перевізника (`carrier_routes`, напрямок «Експорт»):

1. **Рейси цього самого тягача** (номер з Черги є в `plates`) — вага ×4;
2. **рейси перевізника через цей самий пункт пропуску** (`borders`) — ×2;
3. країни, куди через цей виїзд не їдуть (з Ягодина в Румунію), — ×0,15.

Найбільша вага — прогнозована країна, її найчастіші міста — у поясненні («везе, ймовірно, в Німеччину (DUISBURG, KÖLN) — 93% рейсів цього тягача»).
Дата готовності = кордон + дні дороги до країни розвантаження + 1 день на розвантаження + перегін до країни завантаження (~650 км/день).
Немає історії — як раніше: кордон + дні до країни завантаження + 1 день, з позначкою «куди — невідомо».

Для експорту з України (завантаження в Україні) кнопка не показується — черга на виїзд тут не допомагає,
працює наявний «🎯 Підібрати перевізників» за митними даними.

## Встановлення

1. **Supabase → SQL Editor:** виконати `echerha_passed.sql` (таблиця «проїхали кордон» + функція + індекси).
2. **Функція черги:** перерозгорнути `fura-echerha` (у кінці кожної відправки тепер записує, хто зник з черги):
   ```
   supabase functions deploy fura-echerha --no-verify-jwt
   ```
3. **Сайт:** викласти `request-match.js`, `request-match.css` і оновлені `requests.html`, `requests.js`, `agents.js`.

Історія «проїхали кордон» почне наповнюватися з наступної відправки Черги (~30 хв).
До того підбір працює лише за машинами, що стоять у черзі зараз.

## Змінені файли

- `echerha_passed.sql` — нове
- `bot/fura-echerha.ts` — виклик `record_echerha_passed` перед видаленням старого знімка
- `request-match.js`, `request-match.css` — нове (вікно підбору)
- `requests.js` — кнопка в картці запиту; `requests.html` — підключення файлів
- `agents.js` — відкриття з `?request=…&carriers=1,2,3`: обрані перевізники вже відмічені

## Що уточнити на своїх даних

- **Дні дороги** від кордону до країни (`TRANSIT` у `request-match.js`) — середні; поправте під свої рейси.
- **Відповідність кузовів** запиту й Черги (`BODY`): МЕГА/СЦЕПКА → тент, ІЗОТЕРМ → реф/фургон, ЦІЛЬНОМЕТ → фургон.
- **Пункти виїзду для країн** (`EXITS`) — напр., для Італії зараз Угорщина → Словаччина → Польща.
- Місце розвантаження машин з вантажем невідоме — дата готовності орієнтовна, це видно в поясненні.
